# Security findings and assessment

> Evidence limitation: the supplied execution environment had no network access and did not contain Bandit, pip-audit, Trivy, Checkov, Docker, or Helm. The Python test suite could not be collected because `python-jose` was absent and dependency installation failed. Therefore no scanner output is represented as having been produced. The CI workflow is configured to produce the required raw JSON artifacts in a normal GitHub Actions runner. Re-run it before submission and replace this note with the generated reports and confirmed results.

| Finding | Source / type | Severity and rationale | Business impact in VulnTracker | Origin | Status |
|---|---|---|---|---|---|
| User-controlled search interpolated into SQL | Manual / injection | High: query text was concatenated into SQL syntax | An authenticated user could manipulate search queries and potentially read or alter scan data | Starter code | Fixed with bound parameters |
| Scan detail endpoint did not enforce ownership | Manual / broken access control | High: knowing another scan ID exposed its record | Vulnerability details and remediation notes could be disclosed across customer/team boundaries | Starter code | Fixed with owner filter |
| Search results were not scoped to the caller | Manual / broken access control | High: authenticated users could search other users' findings | Cross-tenant disclosure of vulnerability inventory | Starter code | Fixed with owner filter |
| JWT decoder explicitly allowed `none` | Manual / authentication | Critical: unsigned tokens must never be accepted for this signed-token design | Attackers could forge identities if the library accepted an unsigned token | Starter code | Fixed by allowing only configured HS256 |
| Passwords were written to application logs | Manual / sensitive data exposure | High: credentials in centralized logs can be reused and are often broadly accessible | Account takeover and incident-response exposure | Starter code | Fixed; usernames only are logged |
| Unhandled exceptions returned stack traces and request URLs | Manual / information disclosure | Medium: exposes implementation details and potentially sensitive URL data | Helps attackers map internals and may disclose request data | Starter code | Fixed; generic 500 response |
| CORS reflected arbitrary Origin and allowed credentials | Manual / browser security | High: untrusted sites could make credentialed browser requests | Increased risk of cross-origin access to authenticated API responses | Starter code | Fixed by removing permissive custom CORS middleware; configure explicit origins if browser clients are added |
| Share links are bearer capabilities | Manual / shared-report design | Medium: anyone holding the URL can view the report until expiry; password adds a second factor | Forwarded or leaked links expose scan details | New feature | Accepted residual risk; 24-hour expiry, 256-bit random token, SHA-256 token storage, optional bcrypt password |
| Share password is carried in query string | Manual / transport and logging | Medium: URLs can be retained in browser history and intermediary access logs | A valid password may be exposed to log readers | New feature | Required by assignment contract; HTTPS and query-string redaction required in production |
| Development secret fallback exists | Manual / configuration | High if deployed unchanged; known fallback must not be used in production | Forged access tokens if production omits secret injection | Starter code/config | Deployment uses External Secrets; production process must inject a unique secret |

## Scanner selection

- SAST: Bandit (`bandit -r app -f json -o reports/sast.bandit.json`).
- SCA: pip-audit (`pip-audit -r requirements.txt -f json -o reports/sca.pip-audit.json`).
- Container: Trivy (`trivy image --format json -o reports/container.trivy.json vulntracker:1.0.0`).
- IaC: Checkov (`checkov -d helm/vulntracker -o json > reports/iac.checkov.json`).

The four machine-readable artifacts are generated by the CI workflow; they must be reviewed after a successful workflow run. No CVE counts or scanner severities are claimed in this document until those runs complete.
